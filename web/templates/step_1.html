STEP 1 -
Basic parameters

API Key *

You must obtain one to access the Scopus APIs to search and retrieve the articles' information. It has no spaces and is made up of 32 characters containing only letters and numbers. It can be obtained by accessing the Elsevier Portal and registering. If you are part of an educational institution, you can try signing in through your organization or academic email.

e.g. 439f55d263cj...

Year range

The range of years, from the last ten years to the current year, as the target of interest of published articles. The default is the last three years.

e.g. 2014 - 2024

Doctype

The type in which the document is classified. The default is any.

e.g. Article

Pubstage

The publication stage of the document. The default is any.

e.g. Final Document

Language

The language in which the original document was written. The default is any.

e.g. english

Access

Whether the indexed content is open access or not. The default is any.

e.g. Open Access

Source Type

The type of source the document comes from. The default is any.

e.g. Journal

Subject Area

The subject area in which the document is classified. The default is any.

e.g. Computer Science

Pages

Whether the document is short (up to 4 pages, such as research notes) or full (5 or more pages), by page count. The default is any.

e.g. Full papers
