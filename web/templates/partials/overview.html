Overview

This web API is designed to perform systematic bibliographic surveys by querying the Scopus database through its APIs, to gather, validate, and filter the retrieved bibliometric data into a CSV file for studies, theses, research, systematic reviews, etc. It is primarily intended for free academic use by students and researchers, thus promoting access to relevant and high-quality bibliographic sources, allowing them to quickly gather a set of peer-reviewed literature sources through a web form.

Visão Geral

Esta API da web foi projetada para realizar levantamentos bibliográficos sistemáticos consultando a base de dados Scopus por meio de suas APIs, para coletar, validar e filtrar os dados bibliométricos retornados em um arquivo CSV para estudos, teses, pesquisas, revisões sistemáticas, etc. Destina-se principalmente ao uso acadêmico gratuito por estudantes e pesquisadores, promovendo assim o acesso a fontes bibliográficas relevantes e de alta qualidade, permitindo-lhes reunir rapidamente um conjunto de fontes de literatura revisadas por pares por meio de um formulário web.
