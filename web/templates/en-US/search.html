Overview

This application was developed to facilitate the search for articles for research and bibliographic survey of Scopus articles, focused especially on free use by students, improving accessibility. It will use the Scopus Search API and the Scopus Abstract Retrieval API to query the Scopus cluster, and search and retrieve article information if any are found, then return a CSV file. See the Documentation.

Quota and Rate Limits

There is a limit to how many requests for data you can make to Scopus APIs using your API Key. This request quota resets every seven days, and you can check its availability in the response headers. If requests exceed the quota or throttling rate, an error will be returned. See the documentation about weekly quota and requests per second.

Institutional Network *

Please be aware that the API Key will only be properly authenticated and fully released if you use your educational institution's network, which needs to be registered with Elsevier. This does not include VPN or proxy access. Therefore, if you are fully remote and off-campus, the abstract and all authors of the articles will not be returned.

Keywords *

Based on the theme or subject of your research, you must select a minimum of two, and a maximum of four keywords, which will be used as parameters and filters when searching for articles. Each keyword must be written in English, containing only letters, numbers, spaces, hyphens and underscores, with a minimum of 2 and a maximum of 50 characters.

API Key *

You must obtain one to access the Scopus APIs to search and retrieve the articles' information. It has no spaces and is made up of 32 characters containing only letters and numbers. It can be obtained by accessing the Elsevier Portal and registering. If you are part of an educational institution, you can try signing in through your organization or academic email.

e.g. 439f55d263c...

Filtering Options

Optional parameters that can be used to filter search results.

Count
A numeric value, with a minimum of 1 and a maximum of 200, that limits the number of articles to be returned from the search. The default is 50.
Similarity Threshold
A numeric value, with a minimum of 0 and a maximum of 100, used as a threshold to filter and remove similar articles. The default is 80.
Date
Range of years, from the last ten years to the current year, as the target of interest of published articles. The default is the last three years.
