STEP 2 - Additional params

The fields below can be submitted via the "query" query parameter, allowing a Boolean search combining fields with the AND operator to be performed on the Scopus cluster and produce more relevant results. Optional fields left unfilled will not be sent by default. See the Scopus Search Guide.

Date Optional

The range of years, from the last ten years to the current year, as the target of interest of published articles. Default to the last three years.

e.g. 2014 - 2024

Doctype Optional

The type in which the document is classified.

e.g. Article

Pubstage Optional

The publication stage of the document.

e.g. Final Document

Language Optional

The language (in English) in which the original document was written.

e.g. english

Open Access Optional

Whether the indexed content is open access or not.

e.g. Open Access

Srctype Optional

The type of source the document comes from.

e.g. Journal

Subjarea Optional

The subject area in which the document is classified.

e.g. Computer Science

Pages Optional

Whether the document is short (up to 4 pages, such as research notes) or full (5 or more pages), by page count.

e.g. Full papers
